# Draft Timer 共通動作仕様

Windows版とWeb版で共通に保つ、正常系のタイマー進行仕様です。実装変更時は両版の回帰テストをこの仕様に合わせます。

## フェイズと時間

- ピック、インターバル、デッキ構築の制限時間は、設定値をミリ秒へ変換して単調増加時計の経過量で減算する。
- 最後のピックはカウントせず、残った獲得枚数をそのまま受け取る案内だけを行う。
- 一時停止中の実時間は残り時間から引かない。再開後は停止前の残り時間から続ける。
- フェイズ移動と「このフェイズの先頭へ」は、移動先フェイズの案内開始時点へ戻す。
- リセット、タイマー設定の切替、設定保存は先頭の停止状態へ戻す。

## 読み上げ

- 30秒より長い残り時間は、1分単位になった時点で「残りN分です」と読む。
- 30秒以下は、30秒・20秒・10秒で「残りN秒です」と読む。
- 3秒・2秒・1秒は数字だけを読む。制限時間が3秒の場合も開始直後に「3」を読む。
- 一時停止で中断した通常案内は、再開時に同じ文の先頭から読み直す。
- 一時停止中は残り時間の割り込み読み上げを行わない。

## 復元と安全操作

- 進行中は使用タイマー、フェイズ、進行状態、残り時間を端末内へ定期保存する。
- 再読み込み時は自動再生せず、利用者が選んだ場合だけ一時停止状態で復元する。
- 完了、リセット、設定切替、設定保存では復元データを削除する。
- 進行中のリセットと下段の「前のフェイズ」「このフェイズの先頭へ」「次のフェイズへ」は、ポインター操作では0.8秒長押し、キーボード操作では確認を必須とする。
- デスクトップのフェイズ進行一覧からの移動は、進行中の場合に確認を挟む。
